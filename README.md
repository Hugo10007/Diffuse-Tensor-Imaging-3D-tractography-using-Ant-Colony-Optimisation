# Diffuse-Tensor-Imaging-3D-tractography-using-Ant-Colony-Optimisation
Diffuse Tensor Imaging (DTI) is an MRI modality used to measure the direction and intensity water is moving within ones body. By processing this data, we can probabilistically calculate where nerve fibers run within the body/brain by apply natural computing algorithms such as Ant Colony Optimisation (ACO) to trace out said nerve fiber pathways.
